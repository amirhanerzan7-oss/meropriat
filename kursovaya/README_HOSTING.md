# 🌐 Публикация сайта на хостинге

## 📋 Что нужно для демонстрации без компьютера:

### ✅ Вариант 1: PythonAnywhere (Рекомендуется)
**Плюсы:**
- Бесплатный тариф до 500 часов в месяц
- Поддержка Python/Flask
- Легко настроить
- Ваш сайт будет доступен 24/7

**Шаги:**
1. Зарегистрируйтесь на [pythonanywhere.com](https://www.pythonanywhere.com/)
2. Создайте "Web" приложение
3. Загрузите файлы проекта через Git или Upload
4. Установите зависимости: `pip install flask`
5. Настройте WSGI файл для Flask
6. Запустите приложение

### ✅ Вариант 2: Vercel
**Плюсы:**
- Полностью бесплатно
- Автоматический деплой с GitHub
- Высокая скорость

**Шаги:**
1. Создайте репозиторий на GitHub
2. Подключите к Vercel
3. Создайте `vercel.json` файл
4. Автоматический деплой

### ✅ Вариант 3: Запуск с флешки
**Что нужно:**
- Скопировать папку проекта на флешку
- Найти компьютер с Python
- Запустить `START_SERVER.bat`

## 🚀 Быстрый старт для демонстрации:

### На компьютере учителя:
1. Скинуть папку `kursovaya` на рабочий стол
2. Запустить `START_SERVER.bat`
3. Открыть `http://127.0.0.1:5000`

### С телефона/планшета:
1. Установить приложение Termux
2. Скопировать файлы проекта
3. Запустить Python сервер

## 📱 Демонстрация офлайн:

## 🔧 Минимальные требования для хостинга:

### PythonAnywhere Free:
- 512MB RAM
- Python 3.8+
- 1 веб-приложение

### Альтернативные бесплатные хостинги:
- **Glitch** - для быстрых прототипов
- **Replit** - онлайн IDE + хостинг
- **Netlify Functions** - для статических сайтов
